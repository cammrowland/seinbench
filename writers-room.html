Who are you?

This page only works in a browser that has your SeinBench key. The key is a GitHub token that can change only the seinbench repo. To make one:

  1. Open GitHub's new fine-grained token page.
  2. Under Repository access, choose Only select repositories, then pick seinbench.
  3. Under Permissions, set Contents and Actions to Read and write.
  4. Generate it, copy it, and paste it here. It stays in this browser only.
